Non-functional

  • Docker-first deployment; single docker compose up starts db + api + web + mailhog.
  • Low Capex/Opex: runs on a ₹300–500/mo VPS.
  • Automated test coverage target ≥ 80% on backend (vitest + Postgres testcontainer).
  • Responsive down to 320px width; automated Playwright regression across 10 widths.
  • All amounts in paise (BIGINT) to avoid float error.
  • Multi-tenant-ready via community_id on every table.
